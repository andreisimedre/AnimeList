# AnimeList

An iOS application for browsing and discovering anime, built with modern SwiftUI. This app allows users to view detailed information about their favorite anime, including scores, genres, descriptions, and character casts.

## Features

- **Detailed Anime Information:** View comprehensive details for each anime, including English and native titles.
- **Scoring:** See the average score to quickly gauge popularity and quality.
- **Genre Tags:** Filter or identify anime by genre with dynamically loaded tags.
- **Character Cast:** Scroll through a list of characters with their images and names.
- **Dynamic Content Loading:** Load more cast members on demand without leaving the screen.
- **Modern UI:** A clean and responsive user interface built entirely with SwiftUI.

## Tech Stack & Architecture

- **UI Framework:** **SwiftUI** for a declarative and modern user interface.
- **Architecture:** **Model-View-ViewModel (MVVM)** to separate the view logic from the business logic.
- **Concurrency:** **Swift Concurrency (`async/await`)** for handling network requests and data loading in a clean and efficient way.
- **Language:** **Swift**
- **GraphQL**

## Requirements

- Xcode 15.0 or later
- iOS 17.0 or later

## How to Run the Project

To get the project up and running on your local machine, follow these simple steps.

**1. Clone the Repository**

```bash
git clone https://github.com/andreisimedre/AnimeList.git
cd AnimeList
```

**2. Build and Run**
Once Xcode has resolved any packages, you can build and run the project.

• Select an iOS Simulator or connect a physical device.
• Press the Run button (▶) or use the shortcut Cmd+R.

The app should now launch on your selected device or simulator.
